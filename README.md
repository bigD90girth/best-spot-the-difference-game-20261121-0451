Spot the Seven: two original scenes, seven differences each, against the clock. Level 1 is a fishing harbor at sunset; level 2 a mountain village at dawn. Click a difference on either picture and it rings on both. A wrong click costs 5 seconds, a hint costs 50 points. `main.ts` copies `game/` and `screenshots/` to `/output` and writes the dossier.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
